# PDF Translator UX Remake Brief

This page is a compact handoff note for using Stitch with screenshots.

## 1) Copy This Master Prompt First

```text
Design a desktop-first Electron app UI for "PDF Translator".
Tone: precision tool + creative lab. Keep it dark, high-contrast, and information-dense but calm.
Visual style: layered glass panels, subtle atmospheric gradients, compact controls.
Layout:
- Left rail for global nav
- Secondary sidebar for library/settings
- Main workspace canvas
- Right utility panel for OCR/translation controls
- Sticky top toolbar
Typography:
- Thai-friendly sans style similar to Mitr/Sarabun
Interaction:
- Active = blue gradient
- Informational/support = cyan and emerald
- Warning = amber
- Error = rose
Do not output a generic SaaS dashboard. Keep it as a production OCR translation workstation.
```

## 3) Workspace Prompt

```text
Create the main working screen for PDF Translator after opening a file.
Intent: OCR + translation editing cockpit.
Include top toolbar, left document panel, center page canvas, right OCR controls, and export modal.
Phase 3 Feature: Interactive Layer Manipulation - Add layer selection, multi-select (Shift+click),
inline editing (double-click), drag/resize handles, and a floating toolbar for font size,
color, bold, rotation. Show a yellow border on user-edited layers to indicate translation protection.
Color direction:
- Shell #0b0f16
- Top bar #171b23
- Canvas #313741
- Active gradient #2B9BFF -> #2776FF
- Cyan for scope actions, emerald for content actions, amber for warnings, rose for errors

Behavior:
- compact controls, keyboard-friendly, strong selected states
- keep technical workstation vibe
- Ctrl+Z for undo, Delete/Backspace to remove selected layers
Output both wireframe and polished visual version.
```

## 5) Phase 3: Interactive Layer Manipulation UI

When designing the layer manipulation overlay:

- **Selection Box**: White 1px border with 8 resize handles (corners + midpoints)
- **Selected Layer**: Blue border (`#3B82F6`) + light blue fill (`rgba(59,130,246,0.08)`)
- **User-Edited Layer**: Amber border (`#FBBF24`) indicating translation protection
- **Hover State**: Dashed border preview before clicking
- **Inline Editor**: Appears on double-click, shows editable text with color/font toolbar
- **Multi-Select**: Shift+click adds to selection, blue dashed border around all selected
- **Delete Confirmation**: Remove selected layers with Delete key, ghost overlay suppression prevents text bleed-through
- **Undo Indicator**: Visual feedback when Ctrl+Z reverts last action

Key shortcuts:
- `Ctrl+Z`: Undo last layer action
- `Delete/Backspace`: Remove selected layers
- `Shift+Click`: Toggle multi-select
- `Double-click`: Enter inline text edit mode
- `Escape`: Exit inline edit, commit changes
