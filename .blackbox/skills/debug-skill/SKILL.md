# Fix React Bug

## Instructions
- Analyze error logs first
- Identify root cause before suggesting fixes
- Provide minimal code changes only
- Explain WHY the bug happens

## Examples
Input: "TypeError: Cannot read property 'map' of undefined"
Output:
- Cause: state not initialized
- Fix: use default value []
